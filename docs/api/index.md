# API reference

Generated by autodoc straight from the source docstrings; nothing on these
pages is hand-maintained, so nothing on them can drift.

The module docstrings are the point. Most of moonbuggy's design rationale lives
in them — why the parent must never import the module under test, why the cache
key is deliberately coarse, why a mutation that cannot be applied raises rather
than returning — and it survives into these pages rather than being flattened
into a list of signatures.

For the shape of the whole thing rather than the parts, read
[Architecture](../architecture.md) first.
